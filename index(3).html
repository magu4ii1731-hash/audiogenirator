Ниже — рабочая схема в рамках бесплатного тарифа.

Шаг 1. Публикуем этот сайт на GitHub Pages (бесплатный хостинг)

GitHub Pages — бесплатный хостинг статических сайтов. Сайт будет доступен по адресу вида https://ваш-логин.github.io.

ШАГ 1.1

Создайте аккаунт GitHub

  1. Откройте github.com → Sign up.
  2. Введите email, придумайте пароль и логин (он станет частью адреса вашего сайта).
  3. Пройдите проверку-капчу и подтвердите email кодом из письма.
ШАГ 1.2

Создайте репозиторий

  1. Нажмите + (правый верхний угол) → New repository.
  2. В поле Repository name введите: ваш-логин.github.io (точно ваш логин!).
  3. Поставьте галочку Add a README file.
  4. Нажмите Create repository.
ШАГ 1.3

Загрузите файл сайта

  1. Внутри репозитория нажмите Add file → Upload files (или Create new file).
  2. Назовите файл строго: index.html.
  3. Вставьте в него весь код этого сайта (скопируйте всё из скачанного файла index.html — ссылка внизу страницы).
  4. Пролистайте вниз, нажмите Commit changes.
ШАГ 1.4

Включите GitHub Pages

  1. Откройте вкладку Settings → слева меню Pages.
  2. В блоке Build and deployment выберите Source: Deploy from a branch, ветка main, папка / (root) → Save.
  3. Через 1–3 минуты сайт заработает по адресу https://ваш-логин.github.io — откройте его в браузере. 🎉
✅ Готово. Сайт размещён бесплатно и навсегда. Чтобы обновить его — отредактируйте index.html в репозитории (кнопка с карандашом) и сохраните.

Шаг 2. Запускаем бесплатный GPU Google Colab + ComfyUI

ComfyUI — интерфейс для генерации видео нейросетями. Мы запустим его на бесплатном GPU Google Colab и подключимся через туннель. Понадобятся только аккаунты Google и Hugging Face (бесплатные).

ШАГ 2.1

Подготовьте аккаунты

  1. Google-аккаунт — он уже есть, если пользуетесь Gmail/YouTube.
  2. Hugging Face: зайдите на huggingface.co → Sign Up → подтвердите email.
  3. На Hugging Face зайдите Settings → Access Tokens → New token → тип Read → скопируйте токен (вида hf_xxxxxxxx) — он понадобится при скачивании моделей.
ШАГ 2.2

Создайте ноутбук Colab и включите GPU

  1. Откройте colab.research.google.com → + New notebook (при желании сохраните в Google Drive).
  2. В меню: Среда выполнения (Runtime) → Изменить тип среды выполнения (Change runtime type) → Тип ускорителя: T4 GPU → Сохранить.
  3. Проверьте в первой ячейке: вставьте команду ниже и нажмите ▶ (или Ctrl+Enter):
!nvidia-smi

Если видите таблицу с NVIDIA T4 — GPU выдан. Если ошибка — нажмите ▶ ещё раз или переподключите среду (Среда выполнения → Переподключиться).

ШАГ 2.3

Ячейка 1 — установка ComfyUI и модели Wan (I2V, 480p)

Вставьте в новую ячейку и запустите. Скачивание моделей занимает 10–20 минут (~15 ГБ). Вместо ВАШ_ТОКЕН вставьте токен Hugging Face.

Как получить Ngrok-токен (2 минуты): зайдите на ngrok.com → Sign up (email + пароль, карта не нужна) → личный кабинет → Your Authtoken → Copy. Вставьте его в код выше вместо ВАШ_NGROK_ТОКЕН.

⚠️ Не закрывайте вкладку Colab — сессия оборвётся через ~90 минут бездействия. Пока генерируется видео, периодически кликайте по странице. Максимум сессии — ~12 часов.
ШАГ 2.5

Откройте интерфейс и установите Video Helper Suite

  1. Скопируйте ссылку из вывода ячейки 2 (вида https://xxxx.ngrok-free.app) и откройте в новой вкладке.
  2. В интерфейсе ComfyUI нажмите Manager (верхняя панель) → Install Custom Nodes → найдите Video Helper Suite → Install. Этот пакет сохраняет результат в MP4.
  3. Нажмите Restart в появившемся окне.

Шаг 3. Генерируем видео: фото → мультфильм → аниме

Один раз настроили — дальше всё занимает минуты.

ШАГ 3.1

Загрузите рабочий процесс (workflow) Wan I2V

  1. Скачайте файл image_to_video_wan_example.json (правый клик → «Сохранить как»).
  2. Перетащите файл мышкой прямо на окно ComfyUI — появится схема из узлов.
  3. Если какие-то узлы красные: Manager → Install Missing Custom Nodes → перезапуск.
ШАГ 3.2

Настройте модели и параметры

  1. В узле Load Diffusion Model выберите wan2.1_i2v_480p_14B_fp8_e4m3fn.
  2. В Load CLIP → umt5_xxl_fp8, в Load VAE → wan_2.1_vae, в Load CLIP Vision → clip_vision_h.
  3. В узле Load Image — загрузите ваше фото (кнопка choose file to upload). Совет: размер картинки ≈ размеру выходного видео.
  4. Разрешение: 832×480 (48 кадров ≈ 2 сек) — оптимально для бесплатного T4. Генерация одного ролика — 5–15 минут.
ШАГ 3.3

Напишите промпт под задачу

ЗадачаПример промпта (положительный)
Видео из фотоcamera slowly zooms in, the girl smiles and blinks, hair moves in the wind, cinematic lighting
Мультфильм3d pixar style cartoon, character waves and jumps happily, colorful, smooth animation
Анимеanime style, studio ghibli, cherry blossom petals fall, character turns and smiles, soft lighting

Промпт описывает движение и действие, а не содержание картинки (картинка уже задана). Negative-промпт можно оставить стандартным.

ШАГ 3.4

Запуск и сохранение результата

  1. Нажмите Queue Prompt. Прогресс виден в правой панели.
  2. Готовый ролик появится в окне Save Video → нажмите на него правой кнопкой → Сохранить видео как… (MP4).
  3. Длинное видео: сделайте скриншот последнего кадра и подайте его как новое входное фото — так ролики «цепляются» друг за друга.
💡 Чтобы не скачивать модели заново: мы сохранили их в Google Drive (шаг 2.3). При новой сессии Colab просто выполните заново ячейки 2.2–2.4 — установка займёт 2–3 минуты вместо 20.

Частые проблемы и решения

❌ «GPU недоступен / Cannot connect to GPU backend»

Лимит бесплатного GPU на сегодня исчерпан или сервер перегружен. Подождите несколько часов, попробуйте с другого Google-аккаунта или поздно вечером. Либо используйте Kaggle (бесплатно ~30 GPU-часов/нед на P100).

❌ «CUDA out of memory»

Уменьшите разрешение (например, 640×360), уменьшите число кадров до 33–49, убедитесь, что используете fp8-модель, а не fp16. Проверьте !nvidia-smi, что GPU действительно T4.

❌ «You cannot currently connect to this ngrok URL»

Это страница-предупреждение ngrok: нажмите «Visit Site» (иногда нужно обновить страницу). Если не помогает — перезапустите ячейку 2.4, ссылка изменится.

❌ «Tunnel 8188 not found»

Ячейка с main.py должна работать постоянно, с зелёной точкой возле значка среды. Запустите ячейку 2.4 заново и сразу откройте новую ссылку.

❌ Сессия оборвалась посреди генерации

Это норма бесплатного Colab (отключения без предупреждения). Делайте ролики короткими (2–3 сек), сохраняйте результаты сразу, не отходите от вкладки надолго. Модели в Drive при этом не теряются.

❌ Hugging Face просит принять лицензию модели

Зайдите на страницу модели на huggingface.co под своим аккаунтом → кнопка Agree and access repository → повторите скачивание.

💡 Хочу быстрее и без лимитов

Варианты: Colab Pro ($9.99/мес, сессии до 24 ч), RunPod/Thunder Compute (T4/A100 от ~$0.35/час, платите только за время), Kaggle (~30 GPU-часов/нед бесплатно). Схема запуска ComfyUI там та же.
